# Бот для підготовки до НМТ з історії України 2027

Телеграм-бот із тестами у форматі НМТ (4 варіанти, А–Г) і поясненнями до кожної відповіді.

**Режими:** випадковий тест на 10 питань · тест за темою (11 тем, від стародавньої історії до сьогодення) · робота над помилками · статистика за темами.

## Запуск
1. Створіть бота в [@BotFather](https://t.me/BotFather) і отримайте токен.
2. ```bash
   pip install -r requirements.txt
   BOT_TOKEN=ваш_токен python bot.py
   ```

## Як додати питання
Відредагуйте `questions.py`: `q` — питання, `o` — 4 варіанти, `a` — індекс правильного (0–3), `e` — пояснення. Варіанти перемішуються автоматично.
