# Бот для підготовки до НМТ з історії України 2027

Телеграм-бот із завданнями у форматі НМТ і поясненнями до відповідей.

**Завдання всіх чотирьох типів НМТ:** одна правильна відповідь із чотирьох (А–Г), відповідність (1–4 → А–Д), хронологічна послідовність, три правильні з семи.

**Режими:**
- 🎯 Симуляція НМТ: 30 завдань за структурою тесту (20 + 4 + 3 + 3), максимум 54 бали
- 🎲 Швидкий тест: 10 випадкових завдань
- 📚 За темою (11 тем) / 🧩 За типом завдання
- 🔁 Робота над помилками
- 📊 Статистика за темами

Оцінювання: відповідність — 1 бал за пару, «три з семи» — 1 бал за кожну правильну, послідовність — спрощено (3 бали за повністю правильну, інакше до 2).

## Запуск
1. Створіть бота в [@BotFather](https://t.me/BotFather) і отримайте токен.
2. ```bash
   pip install -r requirements.txt
   BOT_TOKEN=ваш_токен python bot.py
   ```

## Банк питань
Усі завдання зберігаються в `questions.json`; формат кожного типу описано на початку `questions.py`.

```bash
python manage_questions.py stats            # статистика банку
python manage_questions.py validate         # перевірка
python manage_questions.py import file.csv  # додати питання з однією відповіддю (див. import_example.csv)
python manage_questions.py import file.json # додати завдання будь-якого типу
```

Офіційні тести НМТ/ЗНО минулих років публікує УЦОЯО на [testportal.gov.ua](https://testportal.gov.ua/). Їх можна перенести в CSV або JSON і імпортувати командою вище.
